# lynnsealnaples.com

Website for Lynn Seal, PA, REALTOR® with Downing-Frye Realty, Inc., Naples, Florida.

Static HTML built by `node build.js` from `data/*.json` and `templates/`. Pushes to `main` publish to GitHub Pages at https://lynnsealnaples.com through `.github/workflows/pages.yml`.

- **Add or change a listing:** ADD-A-LISTING.md
- **Launch checklist, DNS, forms:** LAUNCH-GUIDE.md
- **What changed and when:** CHANGELOG.md
